Чат с ИИ-сотрудником Lemeri AI на вашем сайте — подключение в один клик, без кода.

== Description ==
ИИ-сотрудник отвечает посетителям 24/7, собирает заявки и передаёт их в CRM Lemeri.

== Installation ==
1. Плагины → Добавить новый → Загрузить плагин → выберите lemiri-ai.zip → Установить → Активировать.
2. Настройки → Lemeri AI → «Подключить к Lemeri».
3. Войдите в Lemeri, выберите ИИ-сотрудника — готово.
